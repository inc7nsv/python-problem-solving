# Python Problem Solving

Коллекция моих решений алгоритмических и программных задач на Python с различных платформ для практики и развития навыков программирования.

## О проекте

В этом репозитории собраны решения задач, которые я выполняю для:

- изучения Python;
- практики алгоритмов и структур данных;
- развития навыков решения задач;
- подготовки к техническим собеседованиям.

## Структура репозитория

```text
python-problem-solving/
├── codewars/
├── leetcode/
│   └── easy/
├── project_euler/
└── test.py
```

## Источники задач

### LeetCode
Алгоритмические задачи, часто используемые при подготовке к собеседованиям.

### Codewars
Практические упражнения и задачи различной сложности.

### Project Euler
Математические и алгоритмические задачи, требующие нестандартного подхода к решению.

## Используемые технологии

- Python 3

## Цели

- Улучшение навыков программирования на Python;
- Изучение алгоритмов и структур данных;
- Подготовка к техническим интервью;
- Отслеживание собственного прогресса в обучении.

## Запуск решений

Клонируйте репозиторий:

```bash
git clone https://github.com/inc7nsv/python-problem-solving.git
cd python-problem-solving
```

Запустите нужный файл:

```bash
python путь/к/файлу.py
```
