# Python Problem Solving

Репозиторий с решениями алгоритмических задач на Python, выполненными в рамках обучения, практики и подготовки к техническим собеседованиям.

## О репозитории

Здесь собраны мои решения задач с платформ LeetCode, Codewars и Project Euler. Репозиторий отражает процесс изучения Python, алгоритмов и структур данных, а также демонстрирует подход к решению различных программных задач.

## Разделы

- **LeetCode** — алгоритмические задачи и подготовка к интервью.
- **Codewars** — упражнения для развития навыков программирования.
- **Project Euler** — математические и вычислительные задачи.

## Демонстрируемые навыки

- Python 3
- Алгоритмы
- Структуры данных
- Анализ и решение задач
- Оптимизация кода

## Цель проекта

- Практика программирования на Python;

- Подготовка к собеседованиям;
- Формирование публичного портфолио разработчика.
